# 特征工坊 · 特征工程与标注数据管理平台

面向特征注册与检索、衍生特征工程、时间窗口计算、特征回溯填充、样本分层抽取、标注任务派发、标注质量审核、特征血缘追踪与在线/离线特征服务的数据特征工程与标注管理平台。

这是一个前后端分离的管理平台：前端 Vue 3 + Vite + TypeScript，后端 FastAPI（Python）。
两边各自独立启动，前端 dev server 已关掉自动打开页面，启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端
│   ├── src/views/WorkbenchView.vue|tsx  全部模块共享工作台
│   ├── src/data/modules.ts              18个业务模块配置
│   ├── src/api/              统一请求封装
│   └── vite.config.ts        dev server 配置（open: false）
├── backend/                  FastAPI（Python） 后端
│   ├── app/routers/resource.py  通用查询/导出/登记/动作接口
│   ├── app/services/<key>.py    每个模块独立领域逻辑
│   ├── app/services/base.py     共享服务骨架
│   └── app/store.py          内存数据仓库与示例数据
├── .gitignore
└── docker-compose.yml
```

## 启动

### 后端

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run.sh
```

健康检查：`curl http://127.0.0.1:8000/api/health`

### 前端

```bash
cd frontend
npm ci
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，
需要自己访问。`/api` 由 vite 代理到后端 `http://127.0.0.1:8000`。

## 可追证报告引用（第二版）

历史特征报告过去用「目录名称 + 触发来源」定位审计证据，同名目录可能来自
不同索引，无法唯一落到审计条目。第二版把历史报告的审计来源迁移为按报告
id 建键的引用数据，同名报告不会被合并。

| 接口 | 说明 |
| --- | --- |
| `POST /api/trace/migrate` | 迁移全部报告（或传 `report_ids` 指定报告）；已有引用跳过不覆盖 |
| `GET /api/trace/references` | 列出全部报告引用 |
| `GET /api/trace/reports/{id}` | 报告详情：报告原文、引用状态、候选目录、审计条目、更正与处置 |
| `POST /api/trace/reports/{id}/corrections` | 补交审计更正：须写明原始索引号与审计条目号 |
| `POST /api/trace/reports/{id}/review` | 复查结案或发回补证；结案须写明采用「原签发材料」或「后补证据」 |
| `GET /api/trace/audits/{id}` | 审计详情：引用该条目的报告与处置记录 |
| `POST /api/trace/audits/{id}/dispositions` | 按可追证引用打开实际审计处置（仅已确证引用可打开） |

引用状态：
- `待核`：同名目录跨索引或审计条目有多个候选，不能直接结案或打开实际处置；
- `候选已确证待签发`：更正只证明候选归属、尚未证明签发时点时，可按已确认
  部分办理受限复核结案，余项仍待核；
- `已确证`：索引与审计条目唯一，且具备签发时间（原签发材料或后补证据），
  可完整结案并打开治理审计处置。

报告详情接口会返回迁移后的 `报告引用`、`原始索引号` 和 `采用审计条目号`。

## 约定

- 全部模块共享`frontend/src/views/WorkbenchView.vue|tsx`和一套资源路由。
- 每个模块仍保留独立`backend/app/services/<模块>.py`；纯前端保留
  `frontend/src/domain/<模块>.ts`，用于承载真实业务差异并维持36题位容量。
- 列表接口统一返回 `{ items, total, page, size }`，动作接口统一返回 `{ ok, message }`。
- 状态流转只允许在 `app/services` 里改，路由层不做业务判断。
